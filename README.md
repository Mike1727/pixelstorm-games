# PixelStorm

Marketing website for PixelStorm, a fictional mobile and VR/AR game development studio founded in 2016 in Vilnius. Content is in Russian; code and this README are in English. Static HTML/CSS/JS, no framework or build step.

## Structure
- `index.html` — page markup
- `style.css` — styles
- `script.js` — mobile nav toggle and contact form validation
